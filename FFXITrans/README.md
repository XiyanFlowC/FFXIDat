# FFXITrans - FFXI 汉化插入工具

## 简介
FFXITrans 是一个专为《最终幻想XI》设计的汉化文本插入工具，支持多种游戏数据文件格式的文本翻译和替换。该工具可以将预先准备好的翻译文本插入到游戏文件中，实现游戏界面和内容的中文化。

## 功能特性
- 支持多种FFXI数据格式：XiString、DMsg、EventStringBase、StatusData、ItemData
- 自动备份原始游戏文件
- 支持原位修改或输出到独立目录
- 简体中文到Shift-JIS编码转换
- 失配文本统计和记录
- 灵活的翻译配置系统

## 支持的文件类型

| 类型 | 说明 | 文件内容 |
|------|------|----------|
| `xis` | XiString | 菜单字符串、界面文本 |
| `dmsg` | DMsg | 对话消息、系统提示 |
| `evsb` | EventStringBase | 事件字符串 |
| `sd` | StatusData | 状态效果描述 |
| `iab` | ItemData Armour | 防具数据（名称、描述） |
| `iwb` | ItemData Weapon | 武器数据（名称、描述） |
| `iub` | ItemData Usable | 可使用物品数据 |
| `inb` | ItemData Normal | 普通物品数据 |
| `ipb` | ItemData Puppet | 人偶用装备 |
| `isb` | ItemData Slip | 莫古寄存存单 |
| `fp` | FixedPhrase | 定型文辞书 |

## 使用方法

### 1. 环境准备
- 确保已安装《最终幻想XI》和POL
- 将FFXITrans放置在任意目录
- 准备翻译文本文件

### 2. 配置文件

#### defs.csv - 文件定义
定义要处理的游戏文件，格式：
```csv
路径,类型,语言,注释,Cell索引(可选)
```

**示例配置：**
```csv
ROM/97/8,xis,1,大厅消息
ROM/176/46,dmsg,jp,任务信息,2|3
ROM/119/7,evsb,1,事件字符串
ROM/76/14,sd,1,状态数据
ROM/5/8,iab,1,防具数据
ROM/6/8,iwb,1,武器数据
ROM/7/8,iub,1,可使用物品数据
ROM/4/8,inb,1,普通物品数据
```

#### 翻译文本文件
- **text.txt** - 原始文本（UTF-8编码，转义格式）
- **text_translated.txt** - 翻译文本（UTF-8编码，对应行）
- **text{1-n}.txt** - 原始文本增补，需按顺序递增
- **text{1-n}_translated.txt** - 增补的对应翻译

**文本格式示例：**
```
原始文本示例\n换行符会被转义
原始文本示例2
```

```
对应的翻译文本\n翻译内容
翻译内容2
```

### 3. 运行程序

1. **启动程序**
   ```
   FFXITrans.exe
   ```

2. **选择是否恢复备份**（如果存在备份）

3. **选择处理模式**
   - **原位修改**：直接修改游戏文件（会自动备份，已经存在的备份会被丢弃）
   - **输出到 output**：将处理后的文件保存到 output 目录

4. **程序自动处理**
   - 读取 defs.csv 中定义的文件
   - 应用翻译文本
   - 生成处理报告

### 4. 特殊功能

#### dmsg Cell指定翻译
对于dmsg类型文件，可以指定只翻译特定的列：

```csv
# 只翻译第2列和第3列
ROM/176/46,dmsg,jp,任务对话,2|3

# 只翻译第1列
ROM/175/22,dmsg,jp,角色名称,1

# 翻译所有列（默认行为）
ROM/118/44,dmsg,jp,标准对话
```

**Cell索引规则：**
- 索引从1开始
- 多个索引用`|`分隔
- 无效索引自动忽略
- 只对字符串类型Cell生效


## 故障排除

### 常见问题

1. **"未能正确读取注册表信息"**
   - 确认FFXI和POL已正确安装
   - 以管理员权限运行程序

2. **"翻译文件和原文文件的行数不一致"**
   - 检查text.txt和text_translated.txt行数是否匹配
   - 确认文件编码为UTF-8

3. **翻译效果不生效**
   - 检查defs.csv中的文件路径是否正确
   - 确认翻译文本格式正确
   - 查看text_mismatch.txt了解失配情况

### 输出信息
- **失配文本统计** - 显示未找到翻译的文本数量
- **text_mismatch.txt** - 记录所有失配的原始文本
- **处理进度** - 实时显示当前处理的文件

## 安全提示
- 程序会自动备份修改的文件到 backup 目录
- 建议首次使用时选择"输出到 output"模式测试
- 重要文件请手动备份
- 处理前关闭游戏客户端
